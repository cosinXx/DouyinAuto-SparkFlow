## ✨ 功能特性 🎯

### 🔥 核心功能

- 🔥 **自动续火花**：定时自动给好友发送消息，维持火花 💖
- 👥 **多好友支持**：一个账户支持多个续火花目标 🎯
- 🔍 **智能匹配**：支持按昵称和抖音号两种方式查找好友 🔎
- 📝 **一言支持**：更丰富的消息文本，避免重复 💬

### 🎮 可视化交互

- 🎮 **Web 控制台**：美观的网页界面，操作简单直观 🖥️
- 🟢 **Emotion Ball**：右上角可视化交互小球，实时显示系统状态 😊
- 📊 **运行进度监控**：实时显示任务进度百分比 📈
- ⚠️ **火花预警**：自动检测好友火花天数，快断时高亮预警 🚨

### 🎨 个性化设置

- 🎨 **7种液态玻璃主题**：雾灰（默认）/奶油天空蓝🆕/纯白/抖音红/森绿/奶油黄/深夜，一键切换 🌫️
- 🏷️ **好友备注名**：给好友添加备注，方便管理 📝
- ⏰ **定时发送**：配置多个发送时间点，自动执行 ⏱️
- 🧪 **测试运行**：先测试再正式发送，确保无误 ✅

### 🛡️ 安全保护

- 🍪 **Cookie 过期检测**：及时提醒用户 Cookie 失效 ⚠️
- 🗑️ **一键清除登录信息**：保护用户隐私 🔒
- 🔒 **Cookie 验证机制**：防止多账号数据异常 🛡️
- 🔄 **任务完成静默刷新**：不重启后端即可清除状态提示，界面不中断 ⚡
- 🪪 **真实账号识别**：从 Cookie 识别抖音昵称/抖音号，标题与侧栏胶囊自动显示「{用户名}的火花助手」
