## ✨ 功能特性 🎯

### 🔥 核心功能

- 🔥 **自动续火花**：定时自动给好友发送消息，维持火花 💖
- 👥 **多好友支持**：一个账户支持多个续火花目标 🎯
- 🔍 **智能匹配**：支持按昵称和抖音号两种方式查找好友 🔎
- 📝 **一言支持**：更丰富的消息文本，避免重复 💬

### 🎮 可视化交互

- 🎮 **Web 控制台**：美观的网页界面，操作简单直观 🖥️
- 🟢 **Emotion Ball**：右上角可视化交互小球，实时显示系统状态 😊
- 📊 **运行进度监控**：实时显示任务进度百分比 📈
- ⚠️ **火花预警**：自动检测好友火花天数，快断时高亮预警 🚨

### 🎨 个性化设置

- 🎨 **7种主题颜色切换**：红🔴/绿🟢/黄🟡/灰⚪/白⬜/黑⬛/深灰 🎨
- 🏷️ **好友备注名**：给好友添加备注，方便管理 📝
- ⏰ **定时发送**：配置多个发送时间点，自动执行 ⏱️
- 🧪 **测试运行**：先测试再正式发送，确保无误 ✅

### 🛡️ 安全保护

- 🍪 **Cookie 过期检测**：及时提醒用户 Cookie 失效 ⚠️
- 🗑️ **一键清除登录信息**：保护用户隐私 🔒
- 🔒 **Cookie 验证机制**：防止多账号数据异常 🛡️
- 🔄 **任务完成自动重启**：8.5秒后自动重启后端，清除状态提示 ⚡

## 📋 更新日志 📝

### 🆕 v2.2（最新）✨

#### 🐛 问题优化（多专家深度审计修复）

- 🔧 **后端修复（10项）**：
  - `tasks.py` 添加 `import random` — 启用限流/AI去重时不再崩溃
  - 修复 reader 线程覆盖 "stopped" 状态的竞态 — 手动停止不再显示"出错"
  - `record_run()` 加入调用链 — 运行次数正确记录
  - `_save_memory()` 改为原子写入 — 防止进程崩溃丢数据
  - 消除 TOCTOU 竞态 — 只读一次 .env
  - 后端重启前先终止任务子进程 — 不再产生孤儿进程
  - 移除 .env 内联注释剥离 — 含 `#` 的消息文案不再被截断
  - 火花监控改用容器滚动 — 好友多时能正确加载全部
  - `/api/config` 添加 `ball_position` 处理 — 小球位置支持同步
  - 修复定时任务状态检测不准确的问题

- 🎨 **前端修复（8项 + CSS + 说明书）**：
  - 修复 `previewMessage()` 三处类型错误 — 消息预览正常工作
  - 修复健康检查：移除404端点，修正字段名
  - **删除重复的 `loadStats()`** — 数据从恒为0变为真实值
  - 修复定时任务时间点删除后索引错位
  - 修复好友分组选项与过滤标签不一致
  - 修复好友搜索高亮丢失
  - CSS：补充所有浅色主题的 `--brand-cyan`、运行控制台和欢迎区改为CSS变量驱动
  - **全面更新使用说明书**（修正定时任务位置、补充12项内容）

- 📐 **排版优化**：
  - 定时发送功能从好友页面移到消息页面顶部
